# Retrieval mechanism to benchmark solve

Q8.2 and Q8.3 now use the existing linked benchmark controller path, alongside
Q1.5/Q3.1/Q4.3. The controller forwards its caller-owned retrieval provider and
source-admission port into the real mechanism driver, then runs the benchmark
solver on the actual exported CSV. Every complete cell reserves one mechanism
model call and two solver calls. Provider and solver failures retain their rows.

The solver-visible projection is rebuilt from the verified mechanism journal.
It checks the exact task/source bundle, actual stage, frozen arm, selected source
records and the retrieval material shown to the precursor model. The public
projection carries only the selected documents, their declared qualification and
the false scientific-admission flag. Policy hashes, query intents, variant labels
and usage remain in the controller provenance. Both solver requests receive the
same checked projection. Ordinary retrieval in the Q8.3 control is preserved.

The closed 24-cell synthetic grid exercises custody export, production registry,
the actual model-port fixture transport, bounded source provider, Docker and
read-only trace replay. Its anonymous candidates additionally reach the existing
independent primary-rubric adapter with distinct execution/scoring keys. This
does not add retrieval-specific scientific endpoint scoring or calibration. The
fixture scorer's constant values are interface checks, not benchmark effects.

The original unsupported-scope RED is retained. A provider failure test preserves
all 24 planned cells: six Q8.2 control cells finish, eighteen source-dependent
cells fail before their model calls; no failed cell receives replacement trials.
This path remains train-only. Validation and actual paid-run configuration are
separate obligations, as are the remaining question-to-benchmark connections.

An independent review after the first frozen passing suite found inherited
fixture root IDs such as `q82-correct-s` carrying treatment labels. The new linked
fixtures now map source and root IDs to neutral public identifiers before any
precursor or solver call, preserving shared-root relationships and source text.
Tests inspect identifier values as well as projection field names. The original
passing report remains historical evidence with this review limitation; it is
not evidence of a fully blinded experiment. Real source preparation likewise
requires review of identifiers and content before a frozen paid study.
