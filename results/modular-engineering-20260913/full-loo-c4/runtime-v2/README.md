# C4 runtime v2 engineering evidence

The owning manifest is `FINAL-VERIFICATION.json`; `SHA256SUMS.json` hashes its
companion files. The successful run's complete `controller-receipt.json` records
22 scored target cells, two structurally unavailable without-M2 rows, exact
allocation, individual contrasts, unknown cost categories and the P0 boundary.
Scores are synthetic adapted fixture outputs and have no scientific interpretation.

Each `*-originals.zip` holds the original bytes of that frozen check's retained
runtime artifacts, with a separate path/size/SHA-256 index. The archives include
the controller/build/target receipts, native journals, model-provider request and
response artifacts, public exports, original fixed-history artifacts, scorer
client/worker journals and synthetic failure/rollback state where present.
The original host E-drive directories remain intact. Upstream synthetic primary
repositories, private synthetic reference bodies, authority key files, junction
aliases and Python caches are excluded. Their exclusion is explicit; these
archives are not a self-contained relocated reference-store deployment.

The frozen check helper hashes tracked Python and Markdown source before and
after pytest and preserves JUnit output even on failure. New source was committed
before every test attempt. The initial failure closures remain unchanged:
