Read-only review of `68dcfa8` in `state-improvement-combos` while its final
frozen checks run. This is not an execution closure or scientific verdict.

The new explicit panel type binds a TRAIN history separately from two downstream
TRAIN targets. The ordinary panel's exact training-identity rule remains its
default. The new type fixes history/target roles, the original history binding,
outer plan and complete candidate barrier. Task-disjoint roles do not establish
independent data families; no such family claim is made.

actual frozen history execution and original input artifact hashes. State

qualified history projection, opaque proposal identity and history task; it does
not receive target tasks, target scores, other proposals or raw omitted history.

useful builder under the same reserved proposal/build allocation. The unselected
proposal is preserved for audit and excluded from downstream candidate context.

be sealed before any of the 22 target opportunities. The controller retains two
structural exclusions for the illegal M2-off/M9-on arm. Every downstream model
opportunity closes before evaluator dispatch. The estimand explicitly covers
the history/build and target-state pipeline, rather than implying that only
the downstream state operation changed.

Replay binds complete original build files, selected builder/candidate, history
qualifications, full controller side-effect order, original provider requests,
target state journals, bounded Docker argv and independent score issuance.
M1 qualification parity is checked across build and target arms. Known and
unknown source attempts, failed models/scorers, unavailable builds and target
denominators remain separately recorded.

No concrete blocking defect was found in the reviewed source. The fixtures use
scripted model proposals and scorer outputs. Signatures and replay establish
binding under trusted local authority ownership, not historical scientific
truth, hostile-host attestation, independent-family transfer, model improvement
or official benchmark equivalence. Q6.3 remains a separate experiment phase.
