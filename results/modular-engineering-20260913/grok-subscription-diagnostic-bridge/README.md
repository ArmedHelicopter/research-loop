# Subscription diagnostic bridge engineering evidence

This archive contains the clean frozen source/checks and explicitly synthetic
manifest/request inventories for the included-subscription diagnostic bridge.
No real diagnostic materials or model requests were prepared/dispatched here.
`closure-summary.json` records the tested source commit and exact check counts.
The original four preliminary XMLs are retained, including eight initial setup
errors; those uncommitted runs are not presented as frozen checks. Their separate
stdout/stderr was not captured. The final frozen check preserves original stdout,
stderr, XML, and identical before/after source hash manifests.

The diagnostic contract keeps four TRAIN identities, 36 material slots, 108
review/arbitration and 72 evaluator main opportunities, each reserving one possible
initial title. Unavailable/failed/unknown/unused cases stay in denominators.
Native main usage remains separate from unknown title/all-total/settlement values.
The example 180KB reference inventory contains only digest/byte metadata and was
compiled without truncation. Its capacities are synthetic fixture choices, not
measured real tokenizer/context qualification. Actual limits and complete private
materials require a separately reviewed freeze before any real diagnostic.

Source and protocol details are in `source/docs/GROK_SUBSCRIPTION_DIAGNOSTIC.md`.
The original HTTP positive monetary quote contract and original smoke defaults
are preserved. The diagnostic native receipt adds actual prompt/schema/response/
reservation/source binding checked against private disk receipts before signing.
Coherent response and binding swaps retain known native usage and block later I/O.

`payload-sha256.json` is the exact public payload allowlist. `evidence.zip` contains
only those entries; itself and the outer manifest are excluded to avoid cycles.
`verify_archive.py` compares every decompressed ZIP entry and every disk/index/
committed Git blob byte. The final verification receipt remains outside this
commit so it can name the archive commit without a self-reference cycle.
