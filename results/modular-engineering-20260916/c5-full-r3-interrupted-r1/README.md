# C5 full r3 interrupted evidence

This archive records an interrupted historical run. It does not establish a native terminal result, completion, validation, or scientific effect.

`original-payload-manifest.json` preserves the first payload-only manifest byte-for-byte. `verification.json` records that manifest's hash. The final `published-manifest.json` covers every other canonical file in this directory and intentionally does not hash itself.

Raw task, model, and truth evidence is retained outside Git in the paired private retention directory. Authentication and key material are excluded.
