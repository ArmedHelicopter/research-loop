# M7–M9 production stage artifact seam

C4 now constructs its phase bridge from the actual bounded-choice model context,
the recorded choice, and the actual public retrieval projection. These parent
references are resolved from the same task catalogue and frozen before the
phase. The phase writes an immutable byte copy for allocation, each program and
return, every scheduler event, the sealed M8 SQLite database and the receipt.
The reader replays the phase and requires each expected job/path/event once,
with its original dependency graph. Disabled M7/M8 keep ordinary control outputs;
the serial control creates no SQLite witness.

History builds call the M9 bridge before the restricted interpreter. Selected
builder, TRAIN manifest, parent package, raw returned records, individual files
and success/failure terminal receive separate descriptors. The stage reader
rechecks the actual invocation and replays the selected literal builder. M9's
fixed search allocation and interpreter attempt count are distinct from paid
API or total resource cost. Generic resource attribution remains incomplete.

Audit outputs never change the model request, source selection, selected jobs,
builder DSL or optimization/acceptance permissions. They add durable local I/O.
The audit's own latency and storage overhead still need a paired measurement.

This connects the C4/C5 common stage and the shared phase writer. Other standalone
M7/M8 callers must explicitly provide their own authenticated parent mapping;
other M9 training/deployment paths still need adapters. Passing this seam cannot
be reported as universal host coverage or scientific efficacy. Required module
and combination studies, TRAIN-only optimization and VAL-only acceptance remain.
