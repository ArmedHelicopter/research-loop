## 本轮修复的实验偏差

P0 专用问题不再被错误表达为可关闭的研究模块。Q6.2 固定对照保持原软件包，且不进入优化器。Q6.5 运行两轮影子反馈链，使用认证正确但校准不合格的收据检验拒绝路径，同时用合格收据检验同一保护路径确实能放行。无效计划与模型异常分别记为独立失败事件，并在完整配对面板中保留。

一次完整回归发现调度器遗留 SQLite 句柄，导致 Windows 清理测试数据库时报错。实际原因是连接的事务上下文不会自动关闭连接；修复覆盖初始化、查询及事务异常路径。原失败报告已保留，原跨进程测试和持有强引用的连接释放检查均已通过。
