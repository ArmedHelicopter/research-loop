and unknown settlement separately. A v2 accounting receipt is not reinterpreted

phase opens validation or proves scientific effect. Native integration tests use
the actual native entry with a synthetic process peer below OS spawn, real

existing no-scoring contract; independent scorer integration belongs to the
separate scored benchmark controllers. This document describes implementation;
