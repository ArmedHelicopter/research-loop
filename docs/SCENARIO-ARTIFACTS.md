# M9 离线场景的产物与读取契约

`run_improvement_scenario` 的 Q6.1、Q6.2、Q6.5、Q6.6 现在在实际写入端登记，
封存后经过 `verify_scenario_artifacts` 只读核验，才把成功结果返回调用方。
Q6.3 保留已有专用 fixture builder 适配器。本接口仅用于离线工程 fixture。

每次调用绑定精确 TRAIN 任务、冻结控制、注册实验及变体、独立尝试 ID，以及
场景、适配器和实际存储生产代码的路径、字节数与摘要。回调请求先登记再调用，
返回值必须是精确的 `FrozenRecord` 类型；异常或不合法返回同样保留机会和结果。
VAL 身份与路径联接在目录创建前拒绝。读取端在打开原始输出前检查完整路径树，
包括 Windows junction 和祖先路径，不沿联接读取外部文件。

| 实际产物 | 登记与核验 |
| --- | --- |
| 场景输入和回调请求/返回 | 顺序、父项、TRAIN 任务、冻结控制、完整字段和原始内容 |
| 候选优化器 SQLite | 从注册变体和实际回调派生候选，核对候选表及比较关系 |
| 执行及 shadow SQLite | 核对完整包、活动指针和已消费回执 ID，不只比较条数 |
| 部署当前/前一副本 | 包、memory、活动摘要和校验文件须一致，完整副本均保留 |
| 场景结果 | 独立重建预期操作，核对所有结果字段、限制和 fixture 标记 |
| 原始文件字节 | 每文件描述符及内容寻址副本；严格核对文件与 blob 清单 |
| 目录与终态 | 输入绑定、完整描述符链、源码、终态、seal 和 closure 一起核验 |

读取器从冻结任务和真实回调返回推导预期状态，不把结果文件自述的 digest 当作
预期答案。SQLite 在内存中只读解析，不重新创建运行时或激活包；额外表、视图、
触发器、列及不匹配的行均拒绝。Q6.5 的校准材料是公开合成控制，读取不调用
真实验证服务。Q6.6 的执行、回滚、重复回执、漂移和离线变体各有固定语义。

失败通过 `inspect_scenario_artifact_failure` 读取。即使 SQLite 写入不完整或
已发生副作用后回调报错，也保留实际字节；报告只声明 storage integrity，
明确 `stage_semantics_verified=false` 和 `acceptance_eligible=false`。
封存再失败时保留原异常并附加封存异常类型，已有目录前缀不会伪造为成功。
完整封存缺失时，实际返回关口及读取器均拒绝消费。

任意回调额外写入的文件可以被记录为 `module=None, coverage=uncovered`，
但成功场景读取器要求注册操作的精确文件集；额外文件不能因此自动获得 M9
覆盖或验收资格。需要支持的新文件类型仍须单独定义生产和消费契约。
