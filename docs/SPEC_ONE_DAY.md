## 预算、失败与退路

开发最多 12 个任务、模型调用 60 次；最终至多 32×6=192 次，禁止结果导向重试。每调用超时 180 秒；传输失败、拒绝、截断、非法 JSON 均原样记录为不可用，不补跑。开发/最终加起来总模型 tokens 上限 5,000,000；先到时间、额度、tokens 或调用上限即停止。模型不可用可在开发冻结前显式选现有订阅可用模型并追加日期化说明，冻结后不更换。最终运行中只有预算/安全中止，不进行有利结果早停。

实现修复优先小而直接，最多 8 小时；若关键硬门仍失败则不启动下游最终试验。其余时间用于运行、独立复核和落实决定；不必耗满一天。通过只恢复上述用途；未通过则禁用两仓真实无人复核准入、结论晋升、自动续跑入口，保留单实验选择、脚本执行、数据隔离、原始记录、复算和独立最终复核。只停属于此闭环的任务/自动化，不停其他实验，证据全部保留。交付可立即使用的半自动入口、逐题回执、成本、版本与实际配置验证，随后停用本任务 heartbeat。
