# 旧扩展 TRAIN 导出入口的产物

2026-09-15。`ExtendedTrainProjectionExporter` 继续返回既有 PublicTask，
现在在创建公共文件前建立独立 P0 预约和任务/来源绑定。每个输出目录只接受固定的
公共任务、公共回执、产物目录及其封存文件，不根据回执中的任意文件名打开路径。

`public.json` 与 `receipt.json` 使用排他创建与刷新，目录记录实际字节摘要、大小、
任务、原始 TRAIN 来源摘要、适配器及导出器源码。读取需要调用者给定预期来源摘要，
并核对完整输出清单、原始预约、逐项描述符顺序/父项/来源、终态和 seal。
主导出入口在回读成功之前不会返回该任务。

公共文件写入失败时保存已写部分、失败阶段和异常类型，不记录可能含有私人路径或
源内容的异常消息。该目录只能通过存储完整性检查，不能通过可用任务的返回关口。
封存本身再次失败时保留原始异常及已有前缀；缺少完整 seal 的前缀仍被拒绝。
旧目录不会被覆盖，完整私有划分清单、源内容和权限信息不会复制到此公共产物中。

这一适配器处理旧的本地公开投影格式，与 prospective v2 数据包接口分别验证。
它没有把旧格式自动转换为 prospective v2，也不认证整个私有 custody、操作系统
隔离或真实科学有效性。内容摘要和本地封存可核对字节与绑定，不单独提供外部服务
签发的执行证明或不可篡改存储。配置和部署权限仍由各自可信边界决定。
