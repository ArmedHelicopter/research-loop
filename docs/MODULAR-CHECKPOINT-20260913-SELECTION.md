# 训练选择与 Q4 编译接线检查点

本批源码为 `bd302e7b91771514f1f327f5e0229b5d00baeae3`。控制器、linked 评分与训练选择联调 42 项通过；Q4 材料 bundle、编译器、控制器及相关回归 81 项通过。原始报告、失败复现和各自源码版本归档于 `results/modular-engineering-20260912/train-selection-q4-20260913/`，总索引 413 个文件。本批没有重跑全量回归；前一份 854 项完整回归明确对应 `cc640f7`，不能直接套到新版本。

Q1.5、Q3.1、Q4.3 的训练控制器已支持显式 `linked_benchmark_solve`：预检预算增加求解的两个调用槽，使用托管导出的公开 CSV 和固定 Docker 镜像，逐单元重放机制与求解日志。任何求解失败、超时或不可用都保留在分母，整轮为 `execution_incomplete`。返回的 `linked_results` 可直接进入受信任评分编排，不必再次求解。

独立适配评分组件现在接收实际分析、已执行程序、答案与执行反馈；执行和评分使用不同签名权威。验签后还须核对冻结 rubric、重算聚合值，并与当前日志重新推导出的材料一致。曾复现“签名有效但 rubric 已改变仍被接受”的错误；原失败报告保留，修复后的直接评分与训练选择 24 项专项测试通过，含真实 Docker 到评分器的接线。

训练选择只读取完整训练面板，按相同任务配对、来源组等权、benchmark 等权计算差值；规则及平分次序在面板中冻结。有执行失败则本版选择 inconclusive，不填零分。所选包与候选目录分开绑定，所有 arm 保留为组合候选。该接口不赋予科学有效性、不部署、不签发验证租约，尚未接通独立校准后的验收生命周期。

Q4.1、Q4.2、Q4.4、Q4.5 新机制驱动已加入 registry。每个任务提供一份覆盖全部 Q4 变体的冻结材料 bundle，真实 `compile_train_panel` 按 Q 和 variant 选择材料，未选材料不会整体传给模型。Q4.4 两种反例材料和 Q4.5 两种前后回答材料有实际请求差异及 sentinel 检验。Q4.5 异构变体仍因缺少独立可验证路由证据而失败；这些单元留在完整分母，没有用不同 provider 名称伪装异构执行。其余真实机制端点评分、预算效果和 benchmark 效果仍待测量。

Q1.1/Q1.2 在独立工作树继续修复证据准入、来源绑定、前后更新及撤回语义，尚未纳入本检查点。全部 48 个 Q、单模块、36 对组合、5 个三模块组合、full/LOO、最终组合与 Q6.3 独立元程序阶段仍是任务范围。既有和新增库存状态不变，验证数据仍未获资格；本批无新增付费模型调用、正式效果或验证结果。
