# Shared history candidate × downstream mechanism

This version implements only M4×M9, M5×M9 and M6×M9. Its prospective estimand
is the downstream module × frozen history-candidate interaction, conditional
on one candidate per M9 level within each pair. M4/M5/M6 never vary during
history optimization. M2 is fixed in all optimizer and target arms. M9 uses
only an existing closed TRAIN history, disjoint from target subjects. Different
task IDs within a shared group are not claimed to be independent families.

Twelve factorial arm bindings select six canonical builds: 00 and 10 share
the pair's M9-off candidate; 01 and 11 share its M9-on candidate. The mapping
and six builds are declared before source/model calls, and every original
build plus all twelve bindings must replay before any target call. Each of
the six builds has one useful proposal and one actual restricted-builder
execution. M9-off executes the fixed useful builder; M9-on executes its
original proposal. Shared build cost is charged once, with no discarded
extra proposal calls. This narrow `mechanism-improvement-exposure-v1` contract
leaves the existing eleven-build state-improvement protocol and ordinary
CombinationPanel exact-manifest rule unchanged.

Each of the twelve arms runs both primary prospective TRAIN tasks, retaining
24 target cells with no structural exclusions or pruning. M4 makes a useful
proposal in both arms, and on registers its operational competing predictions
before the fresh target program executes. The observable `target_statistic`
is measured by that execution. Already-observed historical quantities are
conditioning information, not prospective outcomes. Forecast agreement or
successful registration cannot establish causal validity. Matched useful
off proposals may produce the same result as registered plans.

M5 uses two useful reviews of the same candidate and public task. Off gives
the second reviewer the first response; on uses the native sealed review
engine and reveals only after both submissions. M6 uses the native Q8.3
support/counter/methods retrieval mechanism versus matched ordinary retrieval,
with independently signed task/state/corpus/query provenance. Qualifier MACs
bind the original observations and do not establish scientific truth.

The fixed allocation is six history proposal slots/builders, 72 target model
slots (M4: 24; M5: 32; M6: 16), 78 total model slots, 76 qualification calls
(12 history, 48 fixed-state, 16 corpus), 24 retrieval calls, 24 target Docker
allocations and 24 independent primary-scorer process calls. Prior acquisition
of history is recorded separately. Unknown source/model costs block future
I/O; retrieval receipts retain native unknown external monetary cost and exact
reserved/completed item counts. Retrieval failure prevents that cell's model
calls. Failed, blocked and unspent opportunities remain in the denominator.

All target model responses are sealed before any score-input issuance. Replay
requires exact barrier/plan/provider types; original history/source CSV and
qualification records; canonical candidate mapping and builder receipts;
literal model responses; native prediction/review/retrieval journals; shared
request schemas and useful controls; exact Docker limits/mounts; candidate,
panel, rubric and independent scorer bindings. Predictions after execution,
sealed peer leakage, rehashed requests, substituted corpora and proxy barriers
cannot authorize score issuance.

This implementation uses synthetic model/source/reference fixtures with real
restricted builders, Docker and scorer subprocesses. Passing checks is
engineering evidence only. No actual model generation, private benchmark
references or validation data are used. Other pairs, triples, full/LOO panels
and distinct Q6.3 metaprogram experiments remain separate obligations. The
original ten-panel M9 inventory has 47 arm/build-recipe positions and 94 legal
targets plus two structural exclusions; this version explicitly shares six
of the twelve positions in these three pairs rather than executing duplicate
builds or silently changing that historical accounting.
